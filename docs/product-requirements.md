# 生词本服务功能需求

本文整合原始需求与逐轮访谈结论，已于 2026-11-03 经用户整体确认，并包含同日确认的浏览布局、全局搜索及展示模式优化，以及 2026-11-04 访谈中已确认的关系浏览、全局统计、遮挡交互与修改时间规则。

## 1. 产品目标与范围

提供通过 WebUI 使用的个人生词本，支持收集英文单词或短语、记录释义、搜索和整理词条，并通过关系组进行对照学习。

- 第一版只有一份生词本，不涉及多个用户、多个生词本或共享协作。
- 第一版优先在 Windows 上运行验证，优先交付单个可执行文件，通过本机浏览器访问；数据在服务重启后仍然保留。界面适配桌面与移动尺寸。后续支持 Linux Docker 单实例部署，数据目录持久化到容器之外；第一版仍不要求公网部署。
- Windows 默认将持久数据保存在可执行文件旁的 `data` 目录，支持一起移动程序与数据的便携使用方式；允许显式指定其他数据目录。
- Windows 默认仅供本机访问；后续 Docker 的默认部署示例仅向宿主机回环地址发布端口。本阶段不增加账号登录，局域网或公网访问的范围与保护方式留待相应需求出现时确定。
- 前端资源随程序本地提供，基本功能不依赖 CDN 或互联网服务。
- 释义、关系类型及关系说明均由用户维护，不自动查词、创建相关词条或推荐关系。
- 第一版不包含背诵计划、熟悉度、测验、发音播放或批量导入导出。

## 2. 核心概念

术语定义见 [GLOSSARY.md](../GLOSSARY.md)。

- **词条**涵盖英文单词和短语。同拼写判定去掉首尾空格并忽略大小写，同一份生词本内同一拼写只有一个词条。
- **释义**是可表达多个含义的自由文本，允许留空，支持先收词、后补释义。
- **关系组**包含至少两个不同词条，同一词条在同一组内只出现一次。每组只有一种关系类型、一份可选的共享关系说明，不记录派生方向。
- 同组表示这些词条适合围绕某种关联一起学习，不要求任意两个成员都直接符合该关系类型。例如 `draw / drew / drawn` 可以组成屈折变化组，无需认定 `drew` 是 `drawn` 的原形。
- 不同组可以有共同成员，不会因此自动合并，也不会推导跨组关系。例如 `{A, B, C}` 与 `{C, D}` 保持为两个组。
- 词条可以不属于任何关系组，仍能正常搜索、查看和编辑。

关系组的建模理由见 [ADR-0001](adr/0001-model-relations-as-groups.md)。

## 3. 关系类型与说明

第一版采用下列固定分类，用户不能新增、改名或删除类型。

| 类型 | 定义 | 示例 |
| --- | --- | --- |
| 形音相似 | 拼写接近，发音相近或相同，适合一起辨析 | chase / chess / cheese；quiet / quilt；deer / dear |
| 近义 | 在特定含义或用法上接近 | retreat / withdraw / retire；previous / former |
| 反义 | 在特定含义或用法上相反 | forward / backward |
| 词族 | 存在派生或构词关联 | dew / dewy |
| 屈折变化 | 单词的语法变化形式与原形之间的关系 | draw / drew / drawn |
| 拼写变体 | 同一词的不同拼写形式 | centre / center |
| 语义相关 | 属于相近类别、场景或概念，但不直接等同 | pea / bean |

- 同一批词条如果具有多种关系，分别建立不同类型的组，各自维护说明。
- 从任意成员进入同一个组，都看到同一份关系说明。不另设成员说明或组内词对说明；逐词辨析、成员角色和具体用法通过组说明中的自由文本表达。
- 释义和关系说明均采用支持换行的纯文本，编辑时允许清空。第一版不提供 Markdown 渲染、富文本编辑或图片附件。
- 第一版没有独立组名，使用“关系类型＋成员拼写”识别关系组，具体比较主题写在关系说明中。

## 4. 词条管理

- 支持查看词条列表、词条详情及其所属的所有关系组。
- 收录词条与建立关系组在同一页面连续完成：上方收录词条，下方选择组成员及填写关系信息。词条拼写必填，释义可暂时留空；保存词条后留在当前页面，自动加入下方待建组成员并清空输入，可继续收录。允许只收录词条而不建组，也允许仅选择已有词条建组。
- 拼写去掉首尾空格后不能为空，保存时保留输入的大小写、内部空格和标点，不做词典合法性校验。例如 ` Apple ` 保存为 `Apple`，与 `apple` 判重；允许 `give up`、`mother-in-law` 和 `don't`。
- 添加已有拼写的词条时，提示查看已有词条，避免重复。
- 支持修改拼写和释义，所有关联展示使用更新后的内容。
- 修改拼写后若与另一个词条重复，阻止保存并提供已有词条入口。第一版不提供词条合并功能。
- 删除词条前，明确提示它将从所有所属组中移除，以及哪些组会因此被删除。

## 5. 关系组管理

### 5.1 创建与修改

- 从当前词条出发，一次搜索并选择多个已有词条，与当前词条组成关系组，选择类型并可填写说明，最后保存整个组。
- 关系浏览页面右上角提供“建立关系”按钮，与全部词条页面的“收录词条”入口位置一致。两者进入同一收录与建组页面，分别定位到收录区和建组区；自由选择至少两个词条，不固定任何一个成员。收录新词自动加入待建组，已有拼写可直接选择已有词条，不重复收录。
- 从单一关系类型筛选下进入时，建组页面默认选中该类型，允许修改；从所有类型进入时不预选。保存成功后进入新关系组编辑页；取消则返回关系浏览，保留进入前的类型筛选。
- 所需词条不存在时，可以在建组过程中先新增词条，再继续选词。新增词条独立保存，取消建组不会删除这些词条。
- 连续收录保留已选成员与关系草稿；上方词条有尚未保存的输入时，提示先收录或清空输入，再保存关系组。
- 组建立后支持增删成员、修改类型和说明。修改的是共享的组，从任意成员进入均展示更新后的内容。
- 关系组入口直接进入编辑页，不再提供独立的只读详情页；关系浏览及搜索结果的卡片通过“关系类型＋成员数”组头进入编辑，词条详情中的卡片保留“编辑组”入口。编辑页提供“删除关系组”按钮，删除前确认所有词条都会保留。编辑保存、取消或删除成功后返回关系浏览。
- 不保存只有一个成员的组。

### 5.2 重复判定

- 类型相同且成员集合完全相同的组视为重复，与成员排列顺序或说明内容无关。
- 已有“近义：A / B / C”时，不能再建“近义：C / A / B”；可以建立“近义：A / B”或“语义相关：A / B / C”。
- 同成员、同类型但涉及不同义项的辨析，写在同一份组说明中。
- 创建、修改类型或增删成员造成重复时，阻止保存并提示查看已有组，不自动合并说明。

### 5.3 移除与删除

- 从组中移除词条，仅移除成员身份，词条本身保留。
- 删除词条前检查受影响的组；若删除会导致重复组，则阻止整次删除并指出冲突组，由用户自行整理说明、删除多余组后重试。不自动合并说明，也不部分执行词条删除。
- 删除词条时，从其所属的所有组中移除该词条。
- 移除后仍有至少两个成员，保留组及原说明；不足两个成员则删除该组。操作会导致组被删除时，确认前明确提示。
- 删除整个组，不删除任何成员词条。
- 例如从 `{draw, drew, drawn}` 中删除 `drew`，保留 `{draw, drawn}` 和原说明；说明中涉及 `drew` 的文字由用户自行修改。
- 例如已有两个近义组 `{A, B, C}` 和 `{A, B}` 时，删除 C 会使前一个组与后一个组重复，因此阻止删除，原词条和所有组均保持不变。

### 5.4 词条与关系组的修改时间

- 分别记录词条与关系组的修改时间，创建时间保持不变。新记录的修改时间等于创建时间。
- 词条的拼写或释义实际变化时更新修改时间；加入或退出关系组不更新词条修改时间。
- 关系组的类型、说明或成员集合实际变化时更新修改时间，包括删除词条后仍保留的受影响组；成员词条的拼写或释义变化不更新组修改时间。
- 原样保存不更新修改时间；拼写仍按现有规则去掉首尾空格，组成员排列顺序变化不算修改。保存失败或事务回滚时不改变修改时间。
- 升级前已有记录的真实修改时间无法恢复，保留为空，首次实际修改后再记录；原样保存仍保留为空。
- 修改时间由服务端维护，数据库字段为 `updated_at`，API 字段为 `updatedAt`，未知时返回 `null`。时间格式沿用现有 UTC 时间格式。
- 列表的修改日期展示与排序按下述浏览规则执行；修改时间为空时仅在展示和排序中使用添加时间，不回填数据库字段。

## 6. 搜索、浏览与对照阅读

### 6.1 搜索

- 按完整英文、部分英文、中文释义或关系说明中的文字搜索。采用文字包含匹配，英文忽略大小写。
- 去掉搜索输入的首尾空格后，以整段文字作为连续片段匹配，不拆分关键词。例如 `give up` 不会仅因为文本中分别出现 `give` 和 `up` 就命中。
- 搜索入口位于全局顶栏，桌面和移动布局均可使用。输入不会自动跳转；按 Enter 或搜索按钮后，统一进入全部词条页面展示搜索结果，不受当前关系类型筛选限制。
- 搜索文字保存在页面地址中，以便刷新、前进和后退恢复结果。搜索为空或仅含首尾可去除的空格时，回到完整词条列表；关系组仍通过按类型浏览进入。
- 不包含拼写纠错、词形还原、翻译或语义搜索。
- 搜索结果分为词条与关系组两类：拼写或释义命中时展示词条；组说明命中时展示关系组的成员及命中说明。
- 不因组说明命中，就把该组所有成员当作直接命中的词条。

### 6.2 浏览与详情

- 词条列表及搜索直接命中的词条默认最近修改的在前，可切换修改时间升降序、添加时间升降序、英文 A–Z / Z–A。修改时间为空时使用添加时间参与排序，时间相同时按同方向的词条 ID 保持稳定顺序；编辑词条不改变添加时间。
- 网格、瀑布流及搜索结果中的词条卡片统一显示修改日期，修改时间为空时显示添加日期。日期采用浏览器本地时区，仅显示年月日；悬停日期时通过浏览器原生提示显示“添加时间：年月日 时分秒”。手机端同样显示日期，本次不增加手机端查看添加时间的额外操作；词条详情页的日期展示保持原样。
- 删除词条卡片右上角的“详情 ↗”入口，普通模式及遮挡释义模式点击拼写进入详情；遮挡拼写模式在拼写旁保留独立的“↗”图标入口，避免与揭示拼写的操作混用。
- 组内成员按英文 A–Z 展示，忽略大小写，不支持手动排列。
- 详情页的类型分区按本文列出的七种类型顺序展示，同类型下的组默认最近创建的在前。第一版不增加自定义排序。
- 关系浏览默认展示所有类型，使用带类型标记的统一卡片网格，按最近修改在前排列；可筛选单一类型，并切换修改时间、创建时间的升降序。修改时间为空时使用创建时间，时间相同时按同方向的关系组 ID 保持稳定顺序。不为各类型分别添加外框。
- 关系浏览及搜索结果中的关系组卡片右上角显示组自身的修改日期，修改时间为空时使用创建日期；悬停显示精确到秒的创建时间，采用浏览器本地时区，手机端也显示日期。组头“关系类型＋成员数”作为编辑入口，替代右上角的“编辑组 ↗”。
- 上述卡片中的成员通过拼写进入词条详情，仅遮挡拼写模式保留成员旁的独立“↗”入口。成员内容修改不推进组修改时间；搜索命中的关系组与词条详情中的关系组保持既有排序。
- 词条详情展示当前词条的释义，并先按关系类型分区，再逐组展示完整成员的拼写、释义和共享说明。
- 保留每个组的边界。例如 A 属于“近义：A / B / C”及“近义：A / D”时，展示两个独立组。同一相关词条在不同组中可以重复出现。
- 同一批词条的不同类型关系，都可以在当前词条详情页看到。
- 可以进入组内其他词条的详情，继续查看该词条所属的其他关系组。

### 6.3 布局与展示模式

- 侧边栏保留全部词条、关系浏览，移除收录词条导航；全部词条页面保留新增入口。界面中的“关系类型浏览”统一改名为“关系浏览”。
- 关系浏览工具栏左侧依次放展示模式和关系类型筛选，右侧放网格／瀑布流及排序；窄屏按展示模式、类型筛选、布局与排序的顺序换行，布局与排序尽量同排。
- 关系浏览及搜索结果的组头编辑链接在成员数后始终显示“↗”，箭头与组头文字共同进入当前页的组编辑。
- 保留绿色视觉风格。桌面端采用紧凑的多列词条行和自适应多列关系组卡片，减少页面留白、重复标题和内边距；卡片随内容自然增高。非遮挡的词条列表长释义最多显示两行，组内释义完整换行；遮挡区域使用下述统一尺寸规则。
- 移动端单列展示关系组，取消类型外框，成员使用简单分隔线，保留各关系组的独立边界。
- 词条详情中的关系组区域同样不套外层面板，直接以关系类型标题分区，每组保留一层卡片；成员使用紧凑行，当前词条以浅色底和“当前”标记区分。
- 关系说明为空或仅含空白时，在所有展示位置省略整个关系说明区域；编辑表单仍可填写说明。
- 全部词条、关系浏览及搜索结果支持完整模式、遮挡释义、遮挡拼写。两页共用选择，首次默认完整模式，并在同一浏览器中记住选择。
- 遮挡的拼写和释义逐项在鼠标移入时显示、移出时恢复遮挡；单击可固定显示，移出后仍显示，再次单击立即恢复遮挡。收回后若鼠标仍停留在原处，需移出后再次移入才会重新显示。
- 遮挡区域占满所在列的可用宽度，拼写固定预留两行、释义固定预留三行，不根据被遮挡内容的长度或行数调整尺寸。揭示后仍在同一区域展示，超出内容可在区域内滚动，避免成员行和卡片跳动；遮挡拼写揭示后沿用该位置正常拼写的字体。
- 遮挡区域不显示“显示释义”“显示拼写”等提示文字。
- 手机端通过点按显示或收回。固定显示仅在当前页面内有效，切换展示模式或离开页面后恢复遮挡，不保存揭示状态；详情入口独立于揭示操作。
- 遮挡拼写时，组标题使用关系类型和成员数量，不在标题或辅助名称中暴露成员拼写。两种遮挡模式下，关系说明默认折叠，允许主动展开，防止说明提前透露答案。
- 词条详情及编辑页面始终完整显示内容。

### 6.4 全局统计

- 所有页面展示整本生词本的“词条 X · 关系组 Y”，不受搜索文字或关系类型筛选影响；页面内现有结果数量仍表示当前结果数。
- 每个关系组计为一组，不按成员数量拆成词对。例如包含三个词条的一个组计为一组。
- 桌面端放在全局搜索栏右侧，替换“个人词汇收藏”；手机端放在搜索栏下方。
- 新增或删除词条、关系组后同步更新总数，包括删除词条导致关系组被一并删除的情况。
