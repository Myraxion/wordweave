# 网格布局的日期分组与时间轴

状态：方案已确认。

## 已确认

- 修改现有网格布局，按天分组，同一天的内容在组内以网格卡片排列。
- 左侧时间轴用于标示日期、串联日期组，随页面正常滚动；不提供点击跳转或独立滚动。
- 覆盖全部词条、关系浏览与搜索结果的所有网格入口；瀑布流保持现状。
- 搜索结果继续分为词条与关系组两个区域，各自分组。
- 时间排序下，分组日期跟随选中的排序字段：修改时间未知时回退添加／创建时间；添加／创建时间排序则使用添加／创建日期。分组按浏览器本地自然日计算，沿用所选升降序。
- 桌面端与窄屏均将日期放在每组上方，保留短线与圆点；桌面端卡片自适应多列，窄屏卡片单列展示。
- 英文 A–Z／Z–A 排序使用普通网格，不显示日期分组或时间轴，保持全局字母顺序。
- 网格在时间排序下，搜索命中的关系组跟随页面所选时间字段及升降序，替换原有类型优先排序。
- 日期分组状态下，移除词条及关系组卡片上的日期，日期只在时间轴显示。

## 呈现细节

- 时间轴使用完整日期，例如“2026年11月4日”，并注明当前按修改日期或添加／创建日期分组。
- 日期在桌面端与手机端均使用 20px 字号；旁边显示当前日期组下的词条数量或关系组数量，统计随搜索与筛选结果变化。
- 日期旁的数量复用“已收录”和“全部关系组”标题旁的统计胶囊样式。
- 词条与关系组使用同一网格列宽规则：桌面最小卡片宽度 310px、间距 16px，在相同可用宽度下保持相同列数；窄屏沿用单列布局。
- 日期分组中的卡片不再提供原日期对应的创建时间悬停提示；英文排序的普通网格及瀑布流沿用现有卡片日期与悬停提示。
- 英文排序下，搜索命中的关系组继续使用既有类型优先顺序，不参与字母排序；瀑布流中的搜索关系组也保留原规则。
- 只显示有当前结果的日期；日期之间不补空白天数，筛选或搜索后不保留空日期组。无结果时沿用现有空状态，不显示空时间轴。
- 同一天内保持所选时间排序及现有 ID 同方向排序规则，按行排列网格。

## 调整前的现状

- 全部词条、关系浏览和搜索结果共用网格组件，另有瀑布流布局。
- 词条支持修改时间、添加时间及英文排序；关系浏览支持修改时间、创建时间排序。
- 卡片日期采用浏览器本地时区，显示修改日期；修改时间未知时使用添加或创建日期。
- 搜索命中的关系组目前按关系类型及组 ID 排列，不受页面排序选项控制。

术语沿用 [GLOSSARY.md](../GLOSSARY.md)。此处“网格”属于布局，与控制内容遮挡的“展示模式”区分。
