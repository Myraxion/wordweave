# 深色模式

## 已确认的产品行为

- 提供「跟随系统」「浅色」「深色」三种选项，首次使用默认跟随系统。
- 跟随系统时，系统外观变化立即生效；手动选择浅色或深色后，不受系统外观变化影响。
- 覆盖整个应用，包括所有页面、表单、弹窗、悬浮提示、学习遮挡状态及交互状态。
- 保留现有布局和品牌色，采用深灰底色，以不同亮度区分页面、卡片与输入控件，不直接反转颜色或使用纯黑底。
- 分别调整文字、操作状态和控件边界的对比度。
- 主题入口使用始终可见的小按钮，点击轮换三种模式，不新增设置页。
- 主题偏好只保存在当前浏览器，刷新或重新打开后仍有效；未保存偏好时默认跟随系统。
- 按「跟随系统 → 浅色 → 深色 → 跟随系统」循环，点击立即生效并保存。
- 系统、太阳、月亮图标表达当前选择；跟随系统始终显示系统图标。
- 悬浮或键盘聚焦时提示当前选择与下一次点击的作用，并提供相同含义的无障碍名称。

## 调研结果

- 当前只有固定浅色外观；颜色主要集中在 `web/src/style.css`，部分已使用语义变量，多数仍为固定值。
- 已有展示模式与浏览布局偏好保存在当前浏览器，没有服务端偏好设置机制。
- 当前没有设置页；桌面侧栏底部说明区在移动端隐藏，主题入口需要同时考虑桌面和移动端。
- `web/index.html` 另有固定的浏览器主题颜色，原生表单控件也需要随外观适配。

## 实现与验证

- 产品方案已确认，可以开始实现。
- 使用语义颜色变量统一适配主题，普通文字对比度至少 4.5:1，标识控件的边界至少 3:1。
- 首屏应用正确外观，原生控件与浏览器主题颜色随有效主题更新。
- 浏览器行为是本次确认的测试入口；审查基线为实现前的 `6b732dbbaf0c697ea05ba9d1a8b7106f58b5bfce`。
